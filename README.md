# SoloForge

**可视化结构化创作工具** — 用节点图谱组织思维，用权重链路驱动叙事

### 前言

项目使用导出/导入json的方式，将json文件提交给AI生成对应提示词空内容，模块/连线/权重由你随意发挥
- json文件本质上是分配提示词的集合
- 当前3.0版本是本地离线可用
- 没有任何外部API

## 这是什么

SoloForge 是一个基于节点图谱的可视化创作工具。它不是传统意义上的"写作软件"，而是一个**结构化思维组织器**——帮助你把复杂的创作项目拆解为模块，建立模块间的逻辑关系，并通过权重系统控制信息的影响力流向。

简单说：**先搭骨架，再填血肉**。

## 核心特点

### 🧩 模块化创作
- 每个创作单元是一个**模块**，包含标题、多个描述字段、媒体附件
- 模块可自由拖拽、复制、删除，像搭积木一样组织内容
- 每个字段独立折叠/展开，独立设置权重

### 🔗 权重连线系统
- 模块之间通过端口连线建立**逻辑关系**
- 5级权重体系：**决定性 > 高 > 中 > 低 > 不参与**
- 权重决定信息在链路中的影响力——高权重内容会"穿透"低权重内容
- 连线支持贝塞尔曲线/直线，色相/粗细/透明度可调

### 📐 组管理
- 多个模块可打组，形成逻辑单元（如"第一幕""角色设定"）
- 组可折叠/展开，折叠后只显示标题
- 组内模块自动对齐排列

### 🔗 链路视图
- 底部辅助面板，选中任意模块后展示其**上下游完整链路**
- 五线谱式权重线：不同权重的模块排列在对应权重线上
- 可拖拽模块到不同权重线，自动更新权重（磁吸效果）
- 滚轮水平滚动查看完整链条

### 📖 全文预览
- 右侧面板实时预览所有模块的文本内容
- 模块↔全文双向同步：任何一侧修改立即反映到另一侧
- 按组筛选，快速定位内容

### 🖼️ 媒体管理
- 拖拽图片到模块自动生成缩略图预览
- 支持多张图片，原图保存到项目文件夹
- 双击预览图打开原图
- 删除预览图时可选择是否同时删除原图文件

### 🤖 AI 协作
- 内置 AI 提示词模板（角色设定、世界观、情节推进等）
- 支持自定义预设模块
- 一键复制模块提示词，粘贴给 AI 后导入返回的 JSON

### 💾 本地优先
- 基于 File System Access API，项目文件保存在本地文件夹
- 自动保存到 localStorage，刷新不丢失
- 支持导出/导入 JSON，右键另存为新项目
- 模块内容同步保存为 .txt 文件，可用任何编辑器打开

### 🎨 可定制界面
- 连线样式、颜色、透明度可调
- 组框背景/边线透明度可调
- 字体大小、标题字号、亮度可调
- 设置持久化，刷新后保留

## 适用场景

| 场景 | 说明 |
|------|------|
| **长篇小说/系列故事** | 用模块规划章节、角色、世界观，用连线追踪情节线索和因果关系 |
| **剧本/影视创作** | 场景模块化，角色关系可视化，时间线权重控制叙事节奏 |
| **游戏剧情设计** | 任务链、分支剧情、角色好感度系统，权重控制剧情走向 |
| **知识体系梳理** | 概念模块化，逻辑关系连线，权重标注重要性 |
| **项目管理** | 任务拆解为模块，依赖关系连线，优先级用权重表达 |
| **AI 提示词工程** | 模块化组织提示词，权重控制各部分影响力，快速迭代调整 |

## 技术特性

- **零依赖**：纯原生 HTML/CSS/JavaScript，单文件运行
- **无需服务器**：浏览器直接打开即用
- **数据本地化**：所有数据存储在本地，不上传任何服务器
- **File System Access API**：支持直接读写本地文件系统（Chromium 浏览器）
- **响应式画布**：支持缩放、平移、框选、多选
- **撤销/重做**：完整的历史记录栈，Ctrl+Z / Ctrl+Shift+Z

## 快速开始

1. 下载 `SoloForge.html`
2. 用 Chrome / Edge 浏览器打开
3. 点击左上角 LOGO 打开模块库，拖拽模块到画布
4. 点击模块端口（左右圆点）拖拽连线
5. 选中多个模块后 Ctrl+G 打组
6. Ctrl+S 保存项目到本地文件夹

## 数据保存

警告：权重设为[不参与]，单独导出json文件中不会写入这些数据，需要最终单独保存json时，必须把[不参与]改为其他权重。或保存完整文件夹。

## 良性BUG

同一设备打开多个工具时(局域网不同设备未测)，刷新浏览器会多边对齐数据，如果你不想因此丢失数据，将HTML文件丢给AgentIDE：把HTML文件改为独立数据存储。
